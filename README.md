# Dynamic Web Extended — User Guide

This repository hosts the browser-based User Guide for the
Dynamic Web Extended (DWE) addon for Gramps.

## Access the User Guide

Use either of these methods:

- **[Online User Guide](https://johnvitlin.github.io/DWE-User-Guide-Web/)** — read it directly in your browser.
- **[Offline User Guide (ZIP download)](https://github.com/johnvitlin/DWE-User-Guide-Web/releases/latest/download/DWE_User_Guide_Offline.zip)** — download and extract the ZIP file, then open `index.html` in your browser. The complete guide, including its search facility, works without an internet connection.

## About Dynamic Web Extended

For information about DWE, addon installation instructions
and the PDF edition of the User Guide, visit the
[DWE-Addons repository](https://github.com/johnvitlin/DWE-Addons).

This repository contains the generated website guide,
not the DWE addon itself.
