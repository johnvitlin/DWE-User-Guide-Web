1 Introduction¶

This is a guide for

  • Website visitors, describing what they will see and how they can use the Dynamic Web Extended website.

  • Website report creators, explaining how to use the Dynamic Web Extended addon to generate website pages from a Gramps family tree.

Tested in Gramps 5.2 and 6.0

Revised November 2026, John Vitlin

1.1 Summary¶

Dynamic Web Extended (called DWE for short) is a Gramps report addon for creating interactive genealogy websites. It is derived from the Gramps Dynamic Web Report (DWR for short), originally developed by Pierre Bélissent and others, and retains the main features and layout of that report while adding several extensions.

DWE is intended for family-history websites and is useful to explore not only the details recorded for an individual, but also that person's place within their wider family.

The principal additions are:

  • major new features

  • individual and family enhancements

  • website customisation

  • documentation.

DWE does not replace the standard Dynamic Web Report. It is a separate addon, so both reports can be installed and used in Gramps.

This guide concentrates on the features added or changed by DWE. For the underlying features inherited unchanged from Dynamic Web Report, the standard Gramps Dynamic Web Report documentation remains applicable. That documentation is online on the Gramps website.

1.2 About this guide¶

Features inherited unchanged from the standard Gramps Dynamic Web Report are not described in detail.

DWE has been tested with Gramps 5.2 and Gramps 6.0. The test operating system was Windows 10. The screenshots in this guide may differ slightly between Gramps versions, but the operation of DWE is the same. Many screenshots use the Mainz website template, but now there are other themes available some screenshots use those themes.

The web pages of the report can be displayed in different formats at any time, determined by a visitor via a Configuration option. The configuration button (shown as a gear icon) is at the top right of the report’s title bar. The Use tabbed panels instead of sections option determines whether the pages are displayed in tabbed panels or as linear sections. The screenshots in the guide assume the website user has selected the tabbed panels view, but the information in this guide applies to all views.

1.3 Report and website terminology¶

Gramps uses the term report for the Dynamic Web Report. Dynamic Web Extended is similar and is selected from the Gramps Reports menu. Running the report generates a set of web pages that are viewed in a web browser.

In this guide, DWE report generally refers to the report being created in Gramps, while DWE website refers to the generated result viewed in a browser. They are two ways of referring to the same generated family-history material.
