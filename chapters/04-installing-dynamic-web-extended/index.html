4 Installing Dynamic Web Extended¶

Dynamic Web Extended is distributed as a Gramps addon. It uses the standard Gramps addon distribution and installation mechanism and can be installed and updated through the Gramps Addon Manager.

DWE is installed separately from the standard Dynamic Web Report. Installing DWE does not replace or modify the DWR, and both can be available in Gramps at the same time.

DWE has been tested with Gramps 5.2 and Gramps 6.0. The addon supplied for each version of Gramps is built specifically for that Gramps version.

4.1 Installing the addon¶

Dynamic Web Extended can be installed using the Gramps Addon Manager. DWE is distributed through an addon project containing versions of the addon appropriate for supported versions of Gramps.

To install:

1. Open Gramps and select Edit → Addon Manager or click the Addon Manager icon.

2. Create a new addon project (you could name it DWE) using the URL appropriate to your Gramps version:

For Gramps 5.2

https://raw.githubusercontent.com/johnvitlin/DWE-Addons/main/gramps52

For Gramps 6.0

https://raw.githubusercontent.com/johnvitlin/DWE-Addons/main/gramps60

3. Refresh for available addons.

4. Once the project has been enabled, Dynamic Web Extended will appear in the list of available addons. You can find it by entering ‘dynamic’ in the search bar.

Select and install it. If an earlier version of DWE is already installed, the Addon Manager will instead indicate that an update is available and provide an Update button.

5. Restart Gramps if prompted.

Once installed, the report is available in the Gramps menus under Reports → Web Pages → Dynamic Web Extended.

The distribution files and user documentation are maintained at:

https://github.com/johnvitlin/DWE-Addons

4.2 Upgrading DWE¶

When installing a newer version of Dynamic Web Extended, use the addon manager. Your genealogy data is not stored in the DWE addon directory, so upgrading the addon does not alter your family tree.

If you have manually modified files within your DWE installation, make a copy of those changes before upgrading, as addon files may be replaced during installation.

4.3 Removing DWE¶

DWE can be removed without affecting the standard Dynamic Web Report or your Gramps family-tree data. Previously generated DWE websites are also independent of the installed addon and can continue to be viewed.
