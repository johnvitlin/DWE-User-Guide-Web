16 About page for website¶

☑ For creators ☐ For visitors

The DWE top level menu has an About page that displays version details, for diagnostic purposes. It also includes a link to a built-in quick guide. The guide can be edited

16.1 Quick guide¶

The Quick guide is a webpage whose content is stored in a separate file distributed with the website. The website creator, or anyone with access to the generated website files, can edit its contents without regenerating the report.

Visitors can open the Quick guide from a hyperlink on the website's About page.

Note that DWE retains the existing Custom Page facility from the Gramps Dynamic Web Report (DWR). Custom Page allows the website creator to add one or more pages to their website menus using content from Gramps notes. The Custom Page facility is described in the DWR documentation on the Gramps wiki.

16.2 Key difference – Quick guide and Custom pages¶

DWE now has two complementary ways of adding formatted content to a website:

  • Custom pages – sourced from Gramps notes, edit the notes and regenerate the report to see changes;

  • Quick guide – source is an external file, edit the file and refresh the browser to see changes

A more detailed comparison is shown below:

Custom pages Quick guide
From a Gramps note From a Markdown file
Are included in the website's navigation menus Accessed through a hyperlink on the About menu page
Content is maintained inside Gramps Content is maintained in a file within the website folders
Content can include plain text, HTML, Gramps text styling and Markdown Content styling can include plain text and Markdown formatting
Changes require editing the Gramps notes in Gramps and regenerating the report Changes require only editing and saving the accessible Markdown file
Useful for genealogy-related content Useful for website instructions and visitor information

16.3 Key difference – Quick guide and DWE User guide¶

The Quick guide is an editable guide for visitors to a generated website, whereas the DWE User Guide is a comprehensive guide that documents the DWE for visitors and website creators.

16.4 Editing¶

The Quick guide is an editable Markdown file (quick_guide.md) in the website's main directory. It can be edited by anybody who has access to it. Its contents are converted to HTML whenever the Quick Guide page is opened. The file may contain ordinary plain text or Markdown formatting, including headings, lists, hyperlinks and tables.

When a website is first generated, DWE copies its internal default text (quick_guide_default.md) into the website directory as quick_guide.md. Thereafter the website creator can edit quick_guide.md at any time to customise the guide. A visitor just needs to reload the page in their browser to see the new version.

If you later regenerate the website into the same directory, your edited quick guide file is not overwritten.

16.5 Publishing¶

If the website is published to a remote server, changes might be made directly to the remote server's copy by the site manager. Care should therefore be taken when uploading a regenerated website to avoid overwriting edits made on the server. If the website is copied to another computer, the same caveat applies.
