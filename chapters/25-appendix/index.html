25.1 Example Gramps notes¶

The following examples provide starting points for some of the special notes that can be used with DWE. They can be copied as they are into Gramps notes and adapted for a particular website.

All these notes are optional. The relevant sections of this guide describe how each note is selected and used.

  • Some example notes such as Events, Lifespans and Tree Viewer are for display directly on the website and use Markdown for convenient formatting. They could alternatively use plain text, or html.

  • The Parent-child relationship and Local labels notes are plain text notes used inside DWE: DWE reads the content and processes it, so they should follow the syntax shown in their examples and should not be formatted as Markdown.

25.2 Example Events About note¶

This example note uses DWE's MD marker to render the note contents as Markdown. The MD line will not be displayed on the website.

MD
## 25.3 Events {#events}
The events list has been extended, and brings together events for the person and their family.
You can choose to display:

- the person's own events
- events for their parents
- events for their siblings
- events for their spouses
- events for their children
- events in which the person has a role (called Participation events)

Events are normally shown in date order.  Events without dates cannot be positioned chronologically and are not included when the display is limited to the person's lifespan.

Use the checkboxes above the table to choose the information you want to see.  Your display choices are remembered as you move between people in the website.

Event notes can also be shown or hidden.  Hiding notes can provide a more compact view when many events are displayed.

25.4 Example Lifespans About note¶

This example note uses DWE's MD marker to render the note contents as Markdown. The MD line is not displayed on the website.

MD
## 25.5 Lifespans {#lifespans}

This chart shows the lifespans of the person and their immediate family, grouped as parents, siblings, spouses and children.  Marriages are shown as vertical markers.

Select a person's name to open their page in this website.

Use **Date hints** to show or hide date markers, and **Marriages** to show or hide marriage events.  The **Label height** control changes the size of the labels.

The three-dot menu at the top right of the chart can be used to save the chart as an SVG or PNG image.

25.6 Example Tree Viewer About note¶

This example note uses DWE's MD marker to render the note contents as Markdown. The MD line is not displayed on the website.

MD
## 25.7 Tree Viewer {#tree-viewer}

The Tree Viewer provides an interactive view of the family tree centred on the current person.

You can pan and zoom the tree, search for another person, and select people to see more information about them.

You can maximise the tree to use the whole browser space.

Select **Open page for this person** to open the selected person's page in this website.

The View options allow different tree layouts to be selected.  The Download options can save the displayed tree as PDF, PNG or SVG.

25.8 Example Citations About note¶

This example note uses DWE's MD marker to render the note contents as Markdown. The MD line is not displayed on the website.

MD
### 25.8.1 Citations {#citations}

This section lists the citations associated with the individual. Citations are collected from references throughout the Individual's page, including names, events, family members, relationships, places, media and other items.

Consequently, a citation may appear here even when it is not attached directly to the individual.

When displayed as a table:

- **Citation** identifies the citation, including its Gramps ID when enabled.
- **Source** identifies the source associated with the citation.
- **Cited in** describes where the citation is used. Clicking the description takes you back to the corresponding citation reference on the Individual page.
- **Details** displays the citation's recorded information.

The table can be sorted by column and searched across all columns or within a selected column.

The original list view is available.  You can choose between the two formats on the Configuration page.

25.9 Example Parent-child relationship note¶

DWE already contains definitions for the standard Gramps parent-child relationships, so there is no need to copy all the defaults into this note. Include only the relationships whose wording you want to change.

This is not a Markdown note. DWE reads new relationship definitions directly from the note.

See Parent-child relationship note in section 21.6 for the complete syntax and the built-in defaults.

Alternative parent-child relationship phrases
Lines without a > separator can be used as comments.

Adopted > adopting > adopted > A > can produce ‘adopting father’ and ‘adopted son’
Foster > foster > foster > A

25.10 Example Local labels note¶

This example shows how to restore the original DWR wording for Ancestors and Descendants, plus a new label for Why Me.

The Local Labels note is not a Markdown note. DWE reads each label replacement directly from the note. See the Local Labels section [21.7](21-dwe-options.md#local-labels-note) for the complete syntax.

Local label changes

Parents & siblings > Ancestors
Spouses & children > Descendants
Why me > Why is this person in the tree?

25.11 Example Calendar note¶

This example note uses DWE's MD marker to render the note contents as Markdown. The MD line is not displayed on the website. This shows a note suitable for the Calendar About section.

MD
This calendar shows birth, marriage and death events recorded in the family history, arranged by month and day.

**Selecting events**

Use **Living people only** or **All people** to control which events are displayed.  The events available in the calendar depend on the options selected by the website creator.

**Viewing events**

Dates containing events display a number indicating how many events occurred on that month and day.

- Hover over a date to see a temporary preview of its events.
- Click a date to open a popup that remains visible, allowing you to select a person and visit their Individual page.
- Events are listed with the most recent year first.

**Dates without a known day**

Events with a known month but an unknown day are grouped under an asterisk (*) in the bottom-right cell of that month.

**Leap-day events**

29 February is included in every calendar, so events recorded on that date are always accessible.

The arrangement of weekdays reflects the current year, not the historical weekday on which an event occurred.

**Today button**

Select **Today** to scroll to the current date.

(end)
